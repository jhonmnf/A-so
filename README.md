# A-so

Página web pessoal com galeria de imagens, animações e visualização ampliada de fotos.

## Tecnologias

HTML, JavaScript, Tailwind CSS carregado por CDN e Google Fonts.

## Abrir o projeto

Clone o repositório e abra `index.html` em um navegador. Mantenha a pasta `assets/` junto do arquivo HTML. O carregamento de Tailwind CSS e das fontes depende de conexão com a internet.

## Estrutura

- `index.html`: página principal.
- `assets/`: imagens utilizadas na página.
- `index.html\``: arquivo adicional com nome semelhante ao da página principal; sua origem precisa ser revisada antes de qualquer remoção.

## Manutenção

Preserve os caminhos das imagens ao reorganizar os arquivos. Este projeto não possui processo de build nem testes automatizados configurados.
